# Contributing

Fork this public repository, create a branch, and make your changes. Open a pull request describing the change and how you checked it.

Keep scientific claims tied to available measurements. Distinguish satellite detections from separate wildfires, preserve missing data, and explain uncertainty. Do not present correlation as proof of cause. Keep original project attribution and the data-source notes.

Check keyboard access and narrow-screen layout when changing interactions or styling. Owners review and merge pull requests; contributors edit their own forks.
